# Crypto Zombies Contract

A MultiversX smart contract adapted from the [CryptoZombies](https://cryptozombies.io) tutorial. Demonstrates multi-module contract composition, NFT-style ownership, combat mechanics, and cross-contract kitty feeding — making it a practical reference for contracts split across multiple trait modules.

It is also available as an `sc-meta` template (see "Using as a template" below).

## Contract modules

| Module | Description |
|---|---|
| `ZombieFactory` | Create zombies with random DNA; one zombie per address |
| `ZombieFeeding` | Feed a zombie a CryptoKitty (fetched via an async cross-contract call to a CryptoKitties contract) to level it up and mutate its DNA |
| `ZombieHelper` | Level-up fee collection; change zombie name/DNA at higher levels |
| `ZombieAttack` | Attack other zombies; win/loss tracking with cooldown |
| `Storage` | All storage mappers shared across modules |

The `feed_on_kitty` endpoint in `ZombieFeeding` calls out to an external CryptoKitties contract through `KittyOwnershipCall`, a call proxy generated straight from that contract's ABI. `kitty_ownership_abi.rs` is not hand-written: it's generated by the `[[generate-abi]]` entry in `../crypto-kitties/kitty-ownership/sc-config.toml`, so it stays in sync whenever the `kitty-ownership` contract's ABI changes.

## Project structure

```
crypto-zombies/
├── src/
│   ├── lib.rs                     # Contract entry point
│   ├── zombie.rs                  # Zombie struct
│   ├── zombie_factory.rs
│   ├── zombie_feeding.rs
│   ├── zombie_helper.rs
│   ├── zombie_attack.rs
│   ├── storage.rs
│   ├── kitty_obj.rs               # Kitty/KittyGenes/Color structs returned by the CryptoKitties contract
│   ├── kitty_ownership_abi.rs     # KittyOwnership ABI-only call proxy (generated from the crypto-kitties example)
│   └── proxy.rs                   # Auto-generated proxy (sc-meta all proxy)
├── tests/
│   └── crypto_zombies_blackbox_test.rs
├── meta/                         # Build metadata
├── wasm/                         # Wasm build output
├── Cargo.toml
└── multiversx.json
```

## Building

```bash
sc-meta all build
```

## Testing

```bash
cargo test
```

## Using as a template

```bash
sc-meta new --template crypto-zombies --name my-contract
```
